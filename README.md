# BrightPath Learning — Adventure World V3

A React/Vite educational prototype for ages 3–16. Includes the expanded V2 lesson and curriculum data, an adventure-world interface, fictional BrightCoins, a reward shop, simple home/garden inventory, avatar choices, and pet-care interactions.

## Deploy to Render
- Create or update a **Static Site** linked to your separate `brightpath-learning` GitHub repository.
- Build command: `npm install && npm run build`
- Publish directory: `dist`
- Keep `src/main.jsx`, `src/styles.css`, and `public/world.jpg` in their folders.

## Important limitations
- This is a **prototype**, not a complete curriculum. Topic maps are not finished lessons.
- BrightCoins and purchases are fictional; no real payments.
- Progress, purchases and pets are stored in browser localStorage, not a secure online account.
- Avatar selection and home decor are early interactive prototypes, not a full 3D game.
- No user accounts or collection of children's personal information.
- Pet meters change only on interactions; pets cannot die.
- The background illustration is decorative, not a navigable 3D scene.
- Review curriculum accuracy and accessibility before public educational use.

## Run locally
`npm install` then `npm run dev`. Build: `npm run build`.

# BrightPath Learning curriculum coverage

This version includes 41 playable short activities, each with two questions, and a browsable curriculum topic map for Early Years, KS1, KS2, KS3 and KS4. The topic map is not itself a complete set of taught lessons.

The map is an introductory overview inspired by the England EYFS framework and National Curriculum. KS4 subjects and requirements differ by exam board and qualification; do not describe the topic map as a full GCSE specification.

Progress is stored locally in the browser; no parent login, server-side profiles or child data collection is provided. Content has not undergone independent teacher or safeguarding review.

Next steps: systematically author worked examples, differentiated exercises, explanations, assessments and printables for each topic; review against official specifications; implement secure parent-managed accounts and accessibility testing before public marketing.

## Implementation acceptance criteria
For each strand:
1. Provide a functional, accessible adult-supported activity with clear learning purpose and real-world play.
2. Integrate it into age-appropriate child/parent navigation, preserving separate child progress and existing rewards.
3. Include safe setup, flexible alternatives and short optional offline participation.
4. Test it in a production build and supported devices.
5. Link the working experience to an educational requirement, with educator review before marking coverage verified.

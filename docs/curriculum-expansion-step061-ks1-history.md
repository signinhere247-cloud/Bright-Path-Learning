# Step 61 of 250 — KS1 history

Adds four adult-supported historical enquiry guides in `src/ks1HistoryActivities.js`. Year 1: changes within living memory and chronological ordering using fictional events. Year 2: a historically significant individual (Mary Seacole) and interpreting visual historical sources.

The guides include materials, four steps, an enquiry prompt and privacy/safety guidance. The biography requires a sourced, educator-reviewed age-appropriate resource before use; the code does not supply a full historical text. Historical interpretations must distinguish evidence from inference.

These activities are supplementary, do not store personal histories, and are **not yet connected to live learner navigation**. Educator review, local history coverage, significant events and statutory objective-by-objective mapping remain outstanding.
